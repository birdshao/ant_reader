# OID2 印刷微点几何对照：已知码值与扫描裁剪图

**状态：软件研发工具，尚未完成真实打印/扫描仪标定，更不是小蝌蚪 A8S 兼容性认证。**

`oid_print_geometry.py` 为一个已知原始 OID2 码值重建精确数字参考点阵，并将它与同尺寸扫描裁剪图进行比较。适合排查打印缩放、墨点扩散、漏点、错误 OID 码值。在无点读笔时先调试数码制版链路。

## 测量方法

1. 根据 `scripts/sonix_oid2.py` 的 32×32 原始图案重建参考点中心，每块含 7 个定位点和 9 个数据点；仅使用图像内部的完整点，排除边缘裁剪影响。
2. 从单码区灰度扫描图检测小型暗色连通域，计算实际点中心及等效圆直径（面积换算），过滤文字和大墨块。
3. 在 ±4% 尺度范围内进行相位相关粗配准；由于 OID2 高度周期性，随后用固定定位点对平移做 ±8 像素局部细化，再以 RANSAC 拟合受限相似变换。
4. 逐点做一对一匹配，报告预计墨点、匹配、缺失、额外小墨点、中心 RMS 偏差、等效圆点径与相邻基本码块间距。
5. **关键安全校验**：将每个可见 3×3 数据区的四方向偏移还原成 9 个 2-bit 符号，检查 2-bit 校验位，恢复 16-bit 原始 OID。即使几何点匹配率高，只要恢复出另一 OID，也返回 `MISMATCH_EXPECTED_CODE`，不报告匹配成功。

## 用法

环境：Python 3.11+，`pip install -r requirements-scan.txt`。

源图与扫描图必须是**相同尺寸、近似相同画面边界、相同方向的单一重复 OID2 码区**，不能用整张任意角度手机远景直接运行。裁剪区域至少 160×160 像素，最多 400 万像素。当前自动对齐只适用于小平移、约 ±4% 比例误差和基本水平的裁剪。

```powershell
python scripts/oid_print_geometry.py `
  --image scans/oid1345_crop_gray.png `
  --raw-oid 1345 `
  --source-dpi 1200 `
  --scan-dpi 1200 `
  --out evidence/oid1345_geometry.json `
  --overlay evidence/oid1345_overlay.png
```

`--source-dpi` 是重建参考点阵的 DPI（600 / 1200）。`--scan-dpi` 是扫描设备在**这张输入裁剪图上的有效每英寸采样点**，默认等于 `source-dpi`。若原始印码 600 DPI，而扫描仪采用 1200 DPI，**应先将参考/扫描统一到已知采样尺度**，而不是只改变 `scan-dpi` 来蒙混物理尺寸；否则得到的毫米误差没有意义。扫描仪驱动可能插值放大图像，DPI 标签未必等于真实光学分辨率。

报告中的：

- `GEOMETRY_DIGITAL_MATCH`：在该已知码值和选定数字点阵阈值下位置与数据符号匹配，**不是物理点读认证**；
- `MISMATCH_EXPECTED_CODE`：能可靠重建出另一个码值，严重不匹配；
- `INSUFFICIENT_GEOMETRIC_MATCH`：对齐/点径/漏点或数据校验不足，不能认定码值相符；
- `INSUFFICIENT_DOTS`：找不到足够的微点。

`estimated_pitch_mm` 表示基本 **32/600 英寸 = 1.3547 mm** 的重复码块间距（注意不是 8/600 英寸的数据网格点距）；`median_dot_diameter_mm_assumed` 是连通域面积等效圆直径，明显受扫描阈值、像素化、纸张、油墨影响，**不是校准显微镜测量值**。

## 验证范围与局限

11 项新测试使用纯数字合成图，覆盖 600/1200 DPI、三种原始 OID、真实码值不匹配（即使位置相似也拒绝）、平移、+1.5% 缩放、黑点扩大、整块丢点、空白、错误 DPI 假设、异常输入以及 CLI 不覆盖。尚无真实打印扫描、彩色叠码的精密校正、非线性透视和真实 A8S 设备实验。

报告具有 `source_sha256` 方便复核；不覆写任何已有报告或扫描原图。生成的红/绿圆圈仅用于人工核对点位，可能密集，宜放大查看。

要进一步对接 `oid_color_qa.py`，可以先用彩色黑帽算法提取墨点，再生成同尺寸的单色局部裁剪图，之后执行本工具。**彩色区域背景消除引入了自己的阈值误差，不能直接比较光谱反射率。**
