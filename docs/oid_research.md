# A8S 微码/点读包调研（2026-10-25）

本文件将**公开证据**、**推断**、**等待验证**严格区分。

## 已有公开资料的能力

1. A8S 用户指南描述：USB 连接后把 `1.mp3`、`2.mp3` 等拷贝到 `DIY BOOK`，通过橙色原装**内容贴**触发；并提及点读包可以离线使用、点读入口和同码书选择机制。[2025 年 A8S 使用指南](https://www.10100.com/article/106571954)。
2. A8S 指南提到点读包格式和 DAB 兼容性，但没有公开 OID 原始码到音频的精确映射，也没有原生打包命令行接口。[同上](https://www.10100.com/article/106571954)。
3. 传统开放式点读笔教程使用 OidProducer 对 PDF 铺码，给出小达人常见内容码 `25001–27000`、书名码 `56001–56400`、智能码 `65231–65330` 等。这些数字是**其他生态的经验值**，不是 A8S 协议保证。[历史铺码教程](https://www.i-bei.com/baby/thread-51323-1-1.html)。
4. 2022 年公开视频教程称 OidProducer 的铺码书可以用于小蝌蚪等二代码点读笔，还需要相应点读包制作与安装步骤；它**不等于**“随意印码就播放 DIY BOOK 音频”。[铺码教程](https://www.bilibili.com/video/BV1oT411L7Ep/) / [点读包教程](https://www.bilibili.com/video/BV1RG4y1Y7wx/)。
5. 社区有小蝌蚪使用或转换小达人 DAB 点读包教程，但不同设备固件/具体模式兼容性仍需实物确认。[2024 年视频](https://www.douyin.com/video/7358662486175862031)。

## 未证实的关键链路

| 断言 | 当前状态 |
|---|---|
| A8S 能识别家用激光打印机打印的传统 OID 点阵 | 有跨品牌教程支持，尚未针对本机实测 |
| `raw_oid=25001` 可直接触发 `DIY BOOK/1.mp3` | **未经证实** |
| A8S 支持自行生成无贴纸铺码教材所需的某种 DAB/NOD 资源包 | 方向有资料支持；具体格式与流程待测试 |
| Python 能直接原生编码所有 A8S OID、打包 NOD/NOB/NOS | **未发现可确认的官方公开 SDK** |
| 600 DPI 激光打印在任意图文底色上可靠读码 | **未证实；需测试打印矩阵** |

## 编码器研究优先级

1. 找到可信来源的 OidProducer 工具和输出格式说明，观察是否支持批量项目输入/脚本驱动；软件来源必须经过安全核验。
2. 申请厂家提供码段分配范围、铺码版式、音频包导入说明和可否自动化。优先公开或授权方式，降低长期维护成本。
3. 以 **书名码 + 两个内容码 + 对应点读包** 做最小闭环，而不是立刻做 100 页教材。
4. 若可用编码器仅输出固定尺寸 PNG，先测试重复平铺同一码值是否能稳定识别；避免对微点阵几何进行任意图片缩放。
5. 针对 A8S 具体固件保留测试记录。固件升级后重测，不直接假定兼容。
