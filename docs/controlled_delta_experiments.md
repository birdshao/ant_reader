# A8S 控制变量式原生包研究

只处理你自己合法获得的测试包。**这不是 NOB/NOD/NOS 解码器或制包器**，也不能从字节匹配中推断已经成功识别 A8S OID。

## 数据采集

使用可以合法操作的厂商合成工具，以原创短音频生成一个基线包，再**每次只改一个条件**：

1. 基线包：固定书名入口、内容码和音频。
2. OID 变体 1：仅将内容码 A → B，其他参数保持一致。
3. OID 变体 2：仅将内容码 A → C，其他参数保持一致。
4. 音频变体：仅改变音频，不改变 OID 和书名入口。

示例中的 30001、30002、30003 是**假设数据**，不是已获证实的 A8S 有效码段。若厂商工具自动产生时间戳、随机量或压缩数据，文件也可能出现大量变化；不同长度的资源包禁止用同一偏移解释字段。

## 命令

将 `examples/controlled_delta.example.json` 复制到独立的本地测试目录，按实际码值编辑并创建 `private_samples/`，不要把它们提交到 GitHub：

```powershell
python scripts/controlled_delta_lab.py --spec controlled_delta.json --out evidence/controlled_delta_report.json --scan-mib 8
```

工具只允许相对路径，拒绝目录跳转、符号链接及覆盖已有报告；默认检查前 8 MiB，允许 1–32 MiB。

报告包含：`exact_changed_spans`（相同长度时的差异区间）、`numeric_substitution_hypotheses`（数值在 16/32 位大小端与 ASCII 的候选偏移）、`cross_case_same_offset_hypotheses`（多个控制实验共同命中的偏移）。所有候选是启发式证据，**不是格式字段已确认**，报告不含原始二进制数据。
