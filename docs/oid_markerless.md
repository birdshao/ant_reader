# 无辅助标记 OID2 局部图像解码（研究工具）

## 已实现 / 未实现

新增 `scripts/oid_markerless.py`。**不需要 ArUco、书名码映射或提前知道 OID 编号**，对**已裁剪的单一重复 OID2 码图区域**进行自动恢复：傅里叶峰估算微点网格的方向与间距 → 旋转和尺度归一 → 七个定位点的相位匹配 → 九个数据符号及校验位解码 → 多个原始 32×32 码块多数投票。特别使用位于 `(1,16)` 的不对称定位点消除旋转造成的伪有效码。

**范围说明**：这不是任意完整教材页面上的目标检测器；尚未支持大透视变形、明显镜面反射、低分辨率普通手机远景照片、同一裁剪区域混杂多个码值。打印纸要在扫描仪（建议 600/1200 实际扫描 DPI）或手机微距模式下获得足够像素。它也**不能证明 A8S 能够识别图案**。

## 使用方法

依赖安装：

```powershell
pip install -r requirements-scan.txt
```

用裁剪工具选取图文区域中**仅含一种重复 OID2 图案**的局部方形或矩形图（建议宽高至少 160 像素；包含多个基本 1.35 mm 码块），保存为 `crop.png`。文件最大边不超过 2400 像素。无需保留四角标记，也不用知道真实原始码值。

```powershell
python scripts/oid_markerless.py --image scans/crop.png --approx-pitch-px 16 --out evidence/local_decode.json --normalized evidence/normalized.png
```

`--approx-pitch-px` 表示图像上**定位格点间距**（约为基本 32×32 格的四分之一），1200 DPI 原生码图中约为 `16` 像素，600 DPI 中约为 `8` 像素；若拍照后缩放，请填写观察或测量得到的近似间距。可允许一定偏差，但不支持任意尺度全局搜索。

若只是与已知书稿的码值核对，可增加 `--expected-raw-oid 1345`，它**只用于最后比较**，不会影响识别算法，更不会强行返回指定码值。

输出 JSON：`raw_oid`、`status`、`tiles_majority`、`tiles_valid`、`tiles_total`、投票覆盖率、估计的网格方向和网格间距、SHA-256。低覆盖率、码值冲突及空白输入的状态为 `INSUFFICIENT_EVIDENCE`，不返回通过认证的码值。`a8s_compatible` 始终为 `UNTESTED`。

## 验收与局限

本项目自动测试覆盖：多个真实数字 OID2 码值、600/1200 源 DPI、无标记局部裁剪、角度旋转、轻度噪声/模糊、纯白、随机噪声、混合两码值、错误预期码值以及 CLI 防覆盖。**全部是数字合成样本，不是纸张扫描识别成功率**。普通拍照存在非线性局部形变；算法只有整体仿射尺度/角度校正，没有透视矩阵估计。

如果出现“正常码反而被解成其他码”，务必检查不对称定位点，**不能单靠 2-bit 校验位判定有效码**。真实笔采用的光源、传感器及固件规则可能另有约束。本工具基于 [jindroush/albituzka](https://github.com/jindroush/albituzka) 提供的 OID2 基本图案规律，不宣称复制小蝌蚪 A8S 私有协议。
