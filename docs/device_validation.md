# 到货实机验收 SOP — 小蝌蚪 A8S

## 原则与安全

先备份点读笔能看见的文件，不格式化存储，不覆盖已有同名点读包。用经过确认的电源和 USB 数据线，USB 传输完成后安全弹出。所有打印版均按 PDF **实际尺寸 100%** 输出，关闭“适合纸张”和浏览器自动缩放。

## P0：识别笔和音频基础链路（可用原装内容贴作校准）

记录购买版本、固件版本、USB 设备分区、`DIY BOOK` 是否存在、厂家提供的码贴种类、所装书籍包列表。

- 只拷贝 `1.mp3`、`2.mp3`（原创测试音频），分别点原装 001、002 **内容贴**。注意与录音贴/书名贴区分。
- 关机重启，再离线复测相同内容贴；检查重复点读、前导零、设备存储是否生效。
- 这一步只能证实音频链路，不能证明打印的 OID 码已经可用。

## P1：专门的微码测试页（主线）

取得可信 OID 铺码工具后，制作一张**小型独立实验页**，每种候选码标明其来源、原始数值、打印 DPI、码点尺寸、入纸方向。

第一组用于研究传统铺码/点读包：一个书名入口码、两个不同内容码，外加可对应的最简点读资源包。码值如使用 `56001/25001/25002`，必须明确它们只是**传统生态候选码**，先检查已有书包是否占用，再测试。

第二组用于研究内容贴码直印：根据厂家/可信码表导出与原装贴编号 001、002 对应的图案，并和上面生成的 `DIY BOOK` 音频对照；**不要预设 `+25000` 关系**。

对每个图案记录：点读动作、音频或错误提示、是否需要先读书名入口、无线/离线差异、重启是否失效、重复 20 次的正确触发次数。

## P2：打印工艺矩阵

先以**600 DPI 激光黑色碳粉打印**作为试验起点，不把它当最终一定可读的工艺。测试：
- 600 / 1200 DPI（打印机实际支持时）、普通纸 / 哑光纸
- 纯白底 / 浅色插画 / 深色插画
- 图案平铺区域 12×12mm、20×20mm、整张插图区域
- 码点叠印顺序、黑色浓度、透明背景实际效果

记录每组至少 20 次，计算准确率，人工观察是否存在误触发和码值串读。正式大批量前，目标是 **>= 99% 正确触发、0 次触发错误音频**（工程验收目标，非厂商性能保证）。

## P3：完整最小教材

在本仓库 `examples/starter_en.json` 的 1 页样书上，将两个点读区分别绑定真实 OID 原始码（上半插图、下半例句），生成经验证资源包。连续离线、重启、两本书交叉使用并验证碰撞情况。
