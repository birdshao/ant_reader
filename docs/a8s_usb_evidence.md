# A8S 适配器：资源包证据链与 USB 只读扫描 SOP

> 状态：开发工具已通过**模拟文件系统的单元测试**，尚未接触 A8S 真机。它不会解出光学 OID 码，不会生成 `.nob/.nod/.nos`，也不会修改点读笔。

## 为什么优先做这个实验

A8S 用户指南介绍了 `DIY BOOK/<number>.mp3` 内容贴、书名入口、同码书和 NOD/NOB/NOS 资源分发；但没有提供原生 OID 编码规范或可用的公开 Python 制包 API。

视频公开展示的小蝌蚪**授权合成软件**包含“录入封面选书码 → 音频按内容码绑定 → 导出并上传 → 申请在线点读”步骤。授权资格和具体格式必须咨询品牌方；这不是可直接调用的公开 SDK。

实物到货后，最具信息量的实验是：先查看设备存储（如果会暴露为 USB 磁盘），然后**通过官方渠道仅安装一份自己有权使用的点读包**，复查设备侧变化。这样可验证文件实际落点、扩展名及是否是由云端管理的资源。文件名不能用于推断原始 OID 编码。

## 使用环境

- Windows 10/11，Python 3.10+，笔自带数据线；只在该型号通过 USB 显示可读盘符时使用。
- 下面假设点读笔显示为 `E:`，**按实际盘符替换**；绝不执行格式化、磁盘修复、删除或写入。
- 输出放在电脑本地的 `evidence/` 目录，不要把诊断报告（可能包含自己的书名）自动上传公开 GitHub。
- 拍照记录固件版本、具体子型号及“我的书架 → 点读包管理”状态，遮住序列号、账号及配网二维码。

### 步骤 1：首次连接快照

```powershell
python a8s_device_audit.py snapshot --root E:\ --out evidence\before.json
```

默认仅收集疑似点读包（`.nod/.nob/.nos/.dab/.bnf`）及 `BOOK/`、`DIY BOOK/` 一类常见目录下的文件**相对路径、大小及 SHA-256**；默认最多读取并哈希 64 MiB 的单文件，超过只记录大小；不复制音频或资源包。默认跳过隐藏、系统和部分敏感文件。**扫描不是完整磁盘备份。**

### 步骤 2：官方安装最小点读包

使用你已经拥有授权的书及其正常入口，通过 A8S 官方程序/公众号进行安装，确认离线能正常点读。不要导入本文前面生成的 Albi 第三方 OID2 实验 ZIP，因为它**不是小蝌蚪点读包**。

### 步骤 3：第二次快照与差异

```powershell
python a8s_device_audit.py snapshot --root E:\ --out evidence\after.json
python a8s_device_audit.py diff --before evidence\before.json --after evidence\after.json --out evidence\delta.json
```

`delta.json` 中 `added` 表示新增文件，`changed` 表示内容哈希或文件大小变化，`removed` 表示消失。`same_size_unverified` 表示文件未做全量哈希，**不能据此认定文件相同**。

没有差异的常见原因包括：笔不暴露资源分区、资源在内部闪存/云端、安装前已存在该包、USB 仅暴露媒体分区；**不能据此下结论称设备不支持自制书**。

### 步骤 4：只读分析一个可合法研究的本地包

如果官方软件导出或你自己持有一个可读取的点读包：

```powershell
python a8s_device_audit.py header --file "E:\BOOK\example.nob" --out evidence\example_header.json --bytes 64
```

报告包含 SHA-256、文件大小及前 64 字节的 ASCII/十六进制表示。**这是文件指纹，不代表已经解析 `.nob` 格式、解密内容或得到了 OID 码段**。不要未经确认就公开分享第三方版权资源的二进制内容。

## 有了差异之后如何推进主线

1. 找到真实资源包扩展名、路径、安装前后是否生成索引/数据库。
2. 取得品牌方合法的 **OID 源码号段或印码导出工具**，并确认书名码、内容码的最小实例。
3. 使用 `book_assembly.py` 的 `vendor_handoff.csv` 提供 `入口 raw_oid / 内容 raw_oid / MP3`，由授权软件生成最小包。
4. 打印对应原生微码，依次测试**入口 → 单词 → 例句**，记录固件版本、播放与否、误读率。
5. 再评估供应商 CLI/GUI 适配与跨书码值防冲突。**不要用旧的 Albi OID2 码值替代 A8S 原生码段。**

## 公开参考资料及证据冲突

- [小蝌蚪 A8S 新手指南](https://www.10100.com/article/106571954)：入口、同码书、DIY BOOK、NOD/NOB/NOS；页面关于 DAB 的泛化表述未提供直接安装流程。
- [幼学小蝌蚪讲堂：A8S 网盘安装说明](https://www.douyin.com/video/7522358097243884810)：明确表示 A8S `.nob` 可安装，`.dab` **不可以直接放进去**，须向客服申请转换。对 A8S 的直接安装判断优先采用此更具体说明。
- [公开授权合成软件演示](https://www.douyin.com/shipin/7380947731973539859)：封面码、音频索引、资源上传和授权限制。演示所属型号或固件未必与 A8S 一致，仍需要求厂商确认。

## 需要向品牌方确认的技术接口

- A8S 支持的 OID 码制版本、点尺寸/间距、有效书名码和内容码范围、是否能按合法授权导出码图。
- 生成 `.nob/.nod/.nos` 的合成工具或命令行 API，是否支持本地离线自制书及批量导入音频。
- 书名入口和内容码映射规则、重码检测机制、同码书绑定与离线使用。
- 是否对普通用户开放合成工具、是否需要商家账号授权、云端审核流程、商用许可限制。

这几项在获得官方答复或有效的实机材料前均标记为**待验证**。
